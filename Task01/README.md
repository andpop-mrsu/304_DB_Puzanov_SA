# Лабораторная работа 1: Подготовка окружения и работа с SQLite

## Структура файлов:
- Исходные данные (скопированы из dataset/): файлы genres.txt, movies.csv, occupation.txt, ratings.csv, tags.csv, users.txt
- ratings_count.txt: минимальный и максимальный ID пользователя из файла ratings, а также количество записей с этими ID.
- sqlite.txt: номер установленной версии СУБД SQLite и список доступных режимов вывода данных.
